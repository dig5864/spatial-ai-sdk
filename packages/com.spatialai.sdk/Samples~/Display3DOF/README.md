# Display and 3DOF

Install the supplied Spatial Cardboard package, run Spatial AI > Setup > Configure Android XR, then Spatial AI > Display > Create Display and 3DOF Scene. Add Assets/Scenes/SpatialDisplay.unity to Build Settings and build.

This example uses standard XR HMD rotation and display. It does not create a UVC camera or hand inference. The phone optical profile remains a development reference. See the release INSTALL.md for the full workflow.
