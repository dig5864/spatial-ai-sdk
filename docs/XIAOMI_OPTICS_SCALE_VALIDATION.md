## 3. 之前已完成的工作

### 3.1 RhinoX 参考光学管线

- 接入历史 RhinoX Pro `Sharp_2k_Seperate` 双眼网格，每眼 2601 个顶点、5000 个三角形。
- 保留历史网格形状与 UV 方向，通过改造后的 Cardboard 原生层输出。
- 参考配置使用 IPD 0.062 m、近裁面 0.1 m，以及历史非对称视锥：left=-0.07968503 m、right=0.07968503 m、top=0.07348122 m、bottom=-0.08588884 m。
- 这些数值来自 RhinoX 历史配置；尚未证明适用于当前小米手机、镜片和安装方式。

### 3.2 小米屏幕与 AA 区适配

最初做过参考画面的等比例居中显示。用户仍反馈拉伸，随后讨论了按屏幕物理像素尺寸、光学中心及安装条件进行映射的要求。之后根据用户提供的矩形，落实为当前 AA 布局：

| 眼睛 | x | y | width | height |
| --- | ---: | ---: | ---: | ---: |
| 左眼 | 268.220 | 157.045 | 865.054 | 865.054 |
| 右眼 | 1266.727 | 157.045 | 865.054 | 865.054 |

- 每眼分别等比例映射和裁切，不自动叠加刘海安全区偏移。
- 截图确认每眼约 865×865 像素，位置与输入坐标按像素取整后一致。
- 用户确认 AA 区正确；随后调整画面 180° 输出方向。
- 黄色边框移到 AA 区外侧，间隔 2 像素，线宽 3 像素。
- AA 矩形中心不等于已标定的光学中心；这些矩形不能单独证明镜片后的物理尺度正确。

### 3.3 尺度与畸变测试场景

`ImuDiagnostics` 已包含以下目标，并在当前默认 APK 中启动：

| 目标 | 尺寸 | 位置说明 |
| --- | --- | --- |
| 绿色 Cube | 边长 20 cm | 眼睛到物体中心距离 0.6 m |
| 青色 Cube | 边长 40 cm | 眼睛到物体中心距离 1.0 m |
| 橙色 Cube | 边长 40 cm | 眼睛到物体中心距离 1.3 m |
| 粉色 Cube | 边长 40 cm | 眼睛到物体中心距离 1.6 m |
| 棋盘格 | 4×2 m，每格 20 cm | 标靶组局部 Z=2.6 m，Y=0.1 m |

Cube 分布在不同侧向位置；其标注距离是到中心的距离，不是到前表面的距离，也不是沿视线 Z 轴的距离。点按屏幕会归零，并把目标组重新摆到当前朝向。

`OpticsComparison` 已有 2160×2160 测试图，用于观察每眼方向、中心网格和边缘输出。此前的工作主要检查渲染与截图，没有完成镜片中的物理验收。

### 3.4 本轮显示响应修正

- 取消 v2/v3 的轴置换及绝对姿态取逆方案。
- 保留 v4 安装映射：B=identity，M=(0.38268343,0,0,0.92387953)，`invertInputRotation=false`。
- v5 增加显示端俯仰补偿；v6 根据用户要求，同时补偿 Pitch 和 Roll，Yaw 保持。
- 当前小米配置开启 `invertViewPitch` 与 `invertViewRoll`，视图变换为 `qView=(-qHead.x,qHead.y,-qHead.z,qHead.w)`。
- 用户明确要求内容对齐现实水平线：右侧倾头时，画面相对视野向左补偿。此前将“画面向右倾斜”作为正确表现的结论已取消。
- v6 APK 已安装，用户反馈显示正常；433 项 Core 检查通过，诊断运行约 60 FPS。
- 调试白字增加了深色背景，便于观察。

上述变换作用于虚拟视图姿态，不替代镜片投影、畸变、眼位或真实物理头姿标定。

## 4. 恢复执行时的步骤

### 第一步：固定装配，补齐输入参数

- [ ] 确认镜片/光学模组型号，以及是否沿用原 RhinoX Pro 光学模组。
- [ ] 记录反射面和透镜的实际结构，区分平面反射与具有光学作用的曲面。
- [ ] 测量屏幕有效宽高（mm），核对工作分辨率，得到横纵每像素对应的物理尺寸。
- [ ] 记录手机安装位置、倾角、屏幕到镜片和眼睛到镜片的距离。
- [ ] 确定左右眼光学中心在屏幕坐标中的位置，并记录佩戴瞳距和可调范围。
- [ ] 保存装配照片、测量方式和配置版本，后续每轮测试使用相同装配。

如果模组或安装距离与原 RhinoX 条件不同，需要重新评估投影和畸变网格的适用性，不能只按分辨率比例继续缩放参考网格。

### 第二步：单眼几何与可见范围验收

- [ ] 分别遮住左右眼，通过实际镜片观察网格、圆和十字线。
- [ ] 检查中心及边缘是否弯曲、拉伸、偏移或裁切，记录左右眼差异。
- [ ] 检查 AA 区和边框是否进入实际可见范围，定位光学中心与有效视场。
- [ ] 区分像素映射错误与镜片参数错误，再决定调整 AA 映射、投影或畸变。

反畸变输出在裸屏上可能本来就不是圆形；最终形状以通过镜片的观察或测量为准。手机截图继续用于检查渲染输出，但不作为完整光学验收证据。

### 第三步：物理尺度与投影校正

- [ ] 增加正对视线的平面标靶，显示已知宽高和距离，减少 Cube 透视和侧向位置对测量的干扰。
- [ ] 在已测量距离处放置相同尺寸的真实标靶，固定眼睛位置，对比虚拟边界与真实边界。
- [ ] 分别记录横向和纵向尺度误差，并在多个距离及视场位置复测。
- [ ] 根据结果检查每眼投影、FOV、光学中心和畸变映射；不要仅缩放所有场景物体来掩盖配置问题。

现有 20/40 cm Cube 和棋盘格可作为复测目标，但测量时必须明确中心距离、表面距离、标靶朝向及观察位置。

### 第四步：双眼融合与深度验收

- [ ] 先分别确认单眼正常，再双眼观察同一目标。
- [ ] 检查是否能自然融合，有无上下错位、重影及异常左右眼方向。
- [ ] 核对每眼光学中心、投影和 IPD；必要时扩展独立的每眼配置能力。
- [ ] 在近远目标上复测深度关系，并记录眼睛位置改变时的表现。

### 第五步：动态复测、配置保存和验收结论

- [ ] 原地转头、抬头、侧倾及组合动作，检查中心与边缘目标是否滑动、变形。
- [ ] 分别测量角度响应、静止漂移、暂停恢复后的配置及重复佩戴后的表现。
- [ ] 区分旋转跟随问题与缺少位置追踪造成的偏差。当前 3DoF 不补偿前后、左右移动头部，不能按完整 6DoF 世界锁定要求验收。
- [ ] 在测试前约定尺度、形状、双眼对齐和动态误差的允许范围；目前没有正式数值标准，不应临时宣称通过。
- [ ] 保存当前手机＋光学模组＋装配方式对应的配置与测量报告。新光学配置应独立版本化，避免改写所有 RhinoX 设备共用的参考参数。
- [ ] 按验证范围更新状态：IMU、光学、相机外参分别记录，完成相应实测后才更新对应验证标记。
